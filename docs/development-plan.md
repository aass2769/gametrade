# GameTrade 개발 계획과 README 구성

상태: P0 구현 완료, P1 남음  
기준일: 2026-10-15

P0와 목록 정렬은 Laravel 코드로 동작한다. 남은 구현은 페이지네이션과 반응형 레이아웃이다. 파일을 만들기만 한 상태는 완료가 아니다. 브라우저 또는 데이터베이스에서 확인된 동작만 완료다.

## 1. 구현된 범위와 남은 범위

| 구분 | 내용 |
| --- | --- |
| 완료 | 환경, 디렉터리, MySQL 마이그레이션과 시드, 공통 레이아웃, 목록·상세, 회원, 등록·수정·삭제, 내 판매 목록, 권한, 검색·필터, 상태 변경, `/api/v1`, 목록 정렬 |
| 남음 | 페이지네이션, 좁은 화면 레이아웃, README의 화면 캡처 |

공개 조회를 회원 기능보다 먼저 만든 이유는 상품의 `user_id`가 필수이기 때문이다. 회원 없이 등록을 먼저 만들면 임시 사용자 번호를 하드코딩하게 된다. 조회는 시드 데이터로 로그인 없이 확인할 수 있다.

## 2. 지금 코드가 있는 곳

실행 순서는 `README.md`를 따른다. 요약은 Docker로 MySQL을 켜고, `php artisan migrate`, `php artisan db:seed`, `php artisan serve`다.

| 역할 | 위치 |
| --- | --- |
| 화면 주소 | `routes/web.php` |
| API 주소 | `routes/api.php` |
| 화면 | `resources/views` |
| 상품 규칙 | `app/Models/Item.php`, `app/Enums/ItemStatus.php`, `app/Policies/ItemPolicy.php` |
| 입력 검증 | `app/Http/Requests` |
| 테이블 | `database/migrations` |
| 샘플 데이터 | `database/seeders/SampleDataSeeder.php` |
| MySQL 컨테이너 | `docker-compose.yml` |
| 자동 테스트 | `tests/Feature` |

접속 정보는 `.env`다. Git에 넣지 않는다.

## 3. 남은 P1

목록 정렬은 구현되어 있다. `sort`는 `latest`, `price_asc`, `price_desc`만 허용하고, 없는 값은 최신순이다. 내 판매 목록은 최신순 고정이다.

### 페이지네이션

한 페이지 10건이다. `page`는 1 이상의 정수다. 검색어와 게임 필터는 페이지를 옮겨도 유지한다.

### 반응형 레이아웃

좁은 너비에서 목록과 폼이 읽히게 CSS만 조정한다. 넓은 화면의 목록과 등록은 그대로 동작해야 한다.

## 4. README

`README.md`는 이미 있다. 확인한 버전, 실행 방법, 샘플 계정, 없는 기능만 완료형으로 적는다.

| 절 | 적을 내용 |
| --- | --- |
| 프로젝트 소개 | 판매 정보 등록과 조회, 상태 표시까지. 결제는 하지 않는다 |
| 개발 목적 | Laravel에서 요청 처리, 검증, 세션, Eloquent, 권한, API를 한 프로젝트로 보여 준다 |
| 기술 스택 | PHP 8.5, Laravel 13, Docker MySQL 8.4, Blade, Sanctum |
| 주요 기능 | 동작이 확인된 P0만. P1은 구현 뒤에만 이 목록에 넣는다 |
| 실행 방법 | `composer install`, `.env`, `docker compose up -d`, `key:generate`, `migrate`, `db:seed`, `artisan serve` |
| 보안 | 바인딩, 비밀번호 해시, 출력 이스케이프, CSRF, 세션, 작성자 검사, GET 변경 금지 |
| 이후 개선 | 페이지네이션, 반응형. 결제와 채팅은 범위 밖 |

README에 쓰지 않는 것:

- 결제, 정산, 채팅, 이미지 업로드를 지원한다는 문장
- 실행하지 않은 테스트의 통과율
- 운영 서버에 배포했다는 내용
- `.env`의 실제 비밀번호를 문서에 또 복사하는 것

## 5. P0 시연 순서

1. 비로그인으로 목록과 상세를 본다.
2. 게임 필터와 이름 검색을 한다.
3. 회원가입하면 로그인된 채로 목록이 열린다. 로그아웃 후 다시 로그인한다.
4. 상품을 등록하고 상세에서 가격을 수정한다.
5. 판매 중에서 거래 진행 중, 거래 완료로 바꾼다.
6. 다른 계정으로 첫 계정의 상품 수정과 삭제가 거절되는지 본다.
7. 자기 판매 중 상품을 삭제한다.
8. 로그아웃 후 등록 주소가 로그인으로 가는지 본다.
